# 📘 Official Brand Guidelines — Luminex Technologies

**Version**: 1.0  
**Domain**: `luminex.rw`  
**Tagline**: *Intelligent Software. Lasting Impact.*  

---

## 1. Brand Identity & Vision
Luminex Technologies is Africa’s premier remote-first software engineering and digital transformation studio based in Kigali, Rwanda. Our brand represents enterprise security, engineering precision, innovation, and long-term client impact.

---

## 2. Color Palette & Design Tokens

### Primary Brand Colors
- **Luminex Executive Gold (Primary Accent)**:
  - **HEX**: `#D97706` / Bright: `#F59E0B` / Dark: `#B45309`
  - **RGB**: `rgb(217, 119, 6)`
  - **Usage**: Primary buttons, key highlight sections, badge borders, pricing highlights.

- **Royal Sovereign Blue (Secondary Accent)**:
  - **HEX**: `#1E50FF` / Deep: `#1E3A8A` / Cyan: `#00F0FF`
  - **RGB**: `rgb(30, 80, 255)`
  - **Usage**: Interactive links, technical metrics, system badges, code tags.

### Background Rhythms
- **Light Theme Primary Background**: `#FFFFFF` (Pure Clean White)
- **Light Theme Secondary Background**: `#F4F8FC` (Soft Executive Blue Tint)
- **Light Theme Highlight Gold**: `#FFFBF0` (Warm Ivory Highlight)
- **Light Theme Highlight Blue**: `#F0F6FF` (Ice Blue Highlight)
- **Dark Theme Obsidian Backdrop**: `#060812` / `#0B1021` (Luxury Metallic Dark)

---

## 3. Typography Scale

### Primary Heading Font
- **Family**: `'Space Grotesk'`, sans-serif
- **Weights**: 600 (Semi-Bold), 700 (Bold), 900 (Black)
- **Usage**: Page H1, section titles, pricing headers.

### Primary Body Font
- **Family**: `'Plus Jakarta Sans'`, sans-serif
- **Weights**: 400 (Regular), 600 (Medium), 700 (Bold), 800 (Extra Bold)
- **Usage**: Paragraph text, buttons, input fields, navigation links.

---

## 4. Logo Usage Rules
1. **Clear Space**: Always maintain a minimum clear space equal to the height of the "L" emblem around the logo.
2. **Rounded Border Badge**: When placing the logo on light backgrounds, wrap it in a rounded container (`border-radius: 12px; border: 2px solid #D97706; box-shadow: 0 4px 20px rgba(217, 119, 6, 0.35)`).
3. **Don'ts**:
   - Do NOT distort or stretch the aspect ratio.
   - Do NOT change the metallic gold gradient to generic flat yellow.
